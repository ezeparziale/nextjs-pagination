# 🐗 Next.js Pagination

🚀 Demo of **pagination patterns** with real data: server-side pagination, infinite
scroll and an advanced data table with three data strategies. Built with Next.js 16 (App
Router), React 19, Prisma 7 and PostgreSQL.

## 🛠️ Stack

- ⚡ **Next.js 16** — App Router, React Server Components, Server Actions, intercepting
  routes and `typedRoutes`
- ⚛️ **React 19** + **TypeScript** in strict mode
- 🎨 **Tailwind CSS v4** + shadcn/ui components on top of Base UI
- 🗄️ **Prisma 7** + **PostgreSQL 18** (`@prisma/adapter-pg`)
- 📊 **TanStack Table v9**, ✅ **Zod 4**, 🌙 `next-themes`
- 📦 **pnpm** as the package manager
